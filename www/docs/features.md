# 项目功能

Blog API 提供了一套完整的博客功能，以下是详细的功能列表。

## 用户系统

### 用户注册与登录

- 用户注册：用户名、邮箱、密码
- 用户登录：支持邮箱或用户名登录
- JWT 令牌认证
- Token 刷新机制

### 个人信息管理

- 获取用户信息
- 更新个人信息（昵称、头像、简介等）
- 修改密码
- 个人统计数据

## 文章系统

### 文章管理

- 创建文章（标题、内容、描述、封面图等）
- 编辑文章
- 删除文章
- 发布/草稿状态管理
- 文章搜索功能
- 分页获取文章列表

### 文章展示

- 获取文章详情
- 文章浏览量统计
- 文章分类筛选
- 文章排序（最新、热门等）

## 分类系统

### 分类管理

- 创建分类
- 编辑分类
- 删除分类
- 获取分类列表
- 分类下文章统计

## 评论系统

### 评论功能

- 发表评论
- 回复评论（支持多级回复）
- 编辑评论
- 删除评论
- 评论审核功能（管理员）

### 评论展示

- 文章下的评论列表
- 评论回复列表
- 评论点赞功能

## 互动功能

### 点赞系统

- 文章点赞/取消点赞
- 评论点赞/取消点赞
- 获取点赞列表

### 收藏系统

- 创建收藏夹
- 编辑收藏夹
- 删除收藏夹
- 添加文章到收藏夹
- 从收藏夹移除文章
- 获取收藏列表

## 文件管理

### 文件上传

- 支持多种文件格式上传
- 文件大小限制（10MB）
- 文件去重机制（基于哈希值）
- 文件引用计数管理

## 管理员功能

### 用户管理

- 获取用户列表
- 查看用户详情
- 更新用户状态
- 更新用户角色
- 删除用户

### 内容管理

- 获取所有文章
- 删除文章
- 获取所有评论
- 管理评论状态
- 内容审核

### 系统统计

- 系统运行状态
- 用户统计数据
- 内容统计数据
- 系统性能监控

## 安全与防护

### 认证授权

- JWT Token 认证机制
- 基于角色的权限控制（RBAC）
- 资源所有权验证
- 管理员特权管理

### 接口防护

- 令牌桶算法限流
- IP 级别限流：100 次/分钟
- 用户级别限流：1000 次/小时
- 参数验证和数据校验

### 数据安全

- 密码 Bcrypt 加密存储
- SQL 注入防护
- XSS 攻击防护
- 敏感信息过滤

## 性能优化

### 缓存策略

- Redis 缓存热点数据
- 数据库连接池优化
- 限流计数器缓存

### 数据库优化

- 合理的索引设计
- 查询优化
- 分页查询优化
- 读写性能优化

这些功能共同构成了一个完整、安全、高性能的博客 API 系统，为前端开发者提供了学习和实践的完整后端服务。
