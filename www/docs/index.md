# Blog API

> 一个专为前端开发学习者提供的博客后端API系统

## 项目简介

Blog API 是一个功能完整的博客平台后端系统，采用 Go 语言开发，使用 Gin 框架构建 RESTful API。本项目专门为前端开发者和客户端开发者提供了一套完整的博客功能接口，可用于学习、练习和快速构建博客应用。

## 核心功能

- **用户系统**：注册、登录、权限管理
- **文章管理**：发布、编辑、删除文章
- **分类系统**：文章分类管理
- **评论系统**：评论、回复、审核
- **互动功能**：点赞、收藏、分享
- **文件上传**：支持图片和文件上传
- **管理员功能**：用户管理、内容审核

## 技术栈

- **后端**: Go, Gin 框架
- **数据库**: MySQL 8.0
- **缓存**: Redis 6.0
- **认证**: JWT Token
- **ORM**: GORM
- **中间件**: 认证、限流、CORS、日志
